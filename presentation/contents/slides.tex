    \frametitle{Implementasi Atomicity (PostgreSQLUserStoreMixin)}
    \begin{lstlisting}[basicstyle=\ttfamily\scriptsize]
# single-session atomic
async def create_user_with_password(self, input):
    async with self.session() as session:
        user = User(**input.to_dict(...))
        session.add(user)
        credential = Credential(...)
        session.add(credential)
        if input.external_identity:
            session.add(ExternalIdentity(...))
        await session.commit()
        return user
    \end{lstlisting}
    \vspace{0.06cm}
    \smallnote{Masalah: transaksi terpisah menyisakan orphan user. Solusi: atomicity di level penyedia - satu sesi, satu commit untuk user, kredensial, external identity, dan role. 8 test gateway diperbarui.}
